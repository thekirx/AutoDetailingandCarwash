# Owner share pack — Hakum Ops user stories

Plain-language stories for leadership. **No flowcharts** — tabs for every role and page.

## Start here (full pack)

| File | What it is |
|------|------------|
| [USER-STORIES-OWNER.html](./USER-STORIES-OWNER.html) | Clickable tabs in a browser (best for reading) |
| [USER-STORIES-OWNER.pdf](./USER-STORIES-OWNER.pdf) | Full printable pack (every section in order) |

### Tabs included

Start here · Shop day · Pay rules · Night close · Owner · Assistant · Branch Admin · Team Lead · Crew · Ops Lead · Sales · Detailer · Marketing · Video Editor · Investor · Customer · All pages

## Rebuild

```bash
npm run generate:owner-stories
```

This runs `scripts/generate-owner-stories.py` (HTML) then Puppeteer (PDF).
