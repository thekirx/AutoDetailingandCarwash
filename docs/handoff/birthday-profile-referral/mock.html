The fine print

Fair rules.

  • New Hakum customers only — one account per phone number.
  • Reward unlocks after the friend's first paid detailing service or higher at any branch: Interior, Full Exterior or Glass Detailing, Full Care or Custom Package, Paint Maintenance, Ceramic Coating, Nano Ceramic Tint or PPF.
  • Carwash, Express Wash Package and Engine Wash do not count, and rewards cannot be used on them.
  • A refunded or voided sale does not count.
  • Rewards are valid for 3 days after they unlock and cannot be exchanged for cash.
  • Hakum may cancel rewards from fake or duplicate accounts.

Plan

How we build it

Order is easiest-first: two pieces are frontend only and reuse data the app already has; referral needs a real backend (new tables + reward logic) and should only start once the client sets the reward. Nothing is built until you approve these mocks.

Frontend only

01 Birthday greeting

Uses

  • data.birthday.perk + date_of_birth from /api/customer-portal
  • isBirthdayToday() in src/lib/birthdayPerk.js
  • Existing Sheet.jsx

Steps

  1. New BirthdayGreetingSheet — opens once per year (localStorage key, wrapped in try/catch).
  2. BirthdayCard on Home: hero on the day, slim countdown row days 2–30.
  3. Birthday pass on top of Rewards while active.
  4. One wording everywhere (sign-up, Home, Me, Rewards) once the client picks it.
  5. Unit tests for show/hide rules (day, after, claimed, expired, Feb 29); browser test at 375 + 1440.

Touches CustomerAccountPage, CustomerLoyaltyPage, customer-native.css, 1–2 new components. No server change.

Frontend only

02 Profile progress

Uses

  • profile (name, phone, email, date_of_birth) and vehicles from the same portal call
  • isSyntheticCustomerEmail()

Steps

  1. Pure profileCompletion(profile, vehicles) in src/lib/ → steps, %, next step + link. Unit tested.
  2. ProfileProgressCard on Home (replaces "Add your birthday" row, hidden at 100%).
  3. Ring + checklist at the top of Me; anchors on each profile form so "Add ›" scrolls to it.
  4. Desktop /account: same card in the editorial column.

Optional 100% reward = backend (one bonus stamp grant) — only if the client wants it.

Backend + frontend

Phase B — program (backend, needs your OK)
