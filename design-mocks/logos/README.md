# Product brand logos

Drop the supplier logo files in this folder using the exact filenames below.
`node design-mocks/all.js` picks up whatever is here and swaps it into the
"What goes on your car" strip in all six mocks. Any brand with no file falls
back to the current typographic lockup, so a partial set still builds.

| Filename | Brand | Used for |
| --- | --- | --- |
| `clearpro.svg` | ClearPro | Paint protection film |
| `f1-auto-films.svg` | F1 Auto Films | Window film |
| `kisho.svg` | Kisho | Ceramic coating |
| `menzerna.svg` | Menzerna | Polishing compounds |
| `rupes.svg` | Rupes | Polishing systems |
| `sonax.svg` | Sonax | Detailing chemistry |
| `meguiars.svg` | Meguiar's | Surface care |
| `microtex.svg` | Microtex | Towels & applicators |

## What the file needs to be

- **SVG preferred.** `.png` also works — same name, `.png` extension.
- **Transparent background.** A white box behind the mark will show as a white
  box on the navy sections.
- **The horizontal wordmark**, not the square icon or app tile. These sit in a
  row, so wide-and-short is right and square marks get shrunk to nothing.
- **PNG only:** at least 600px wide so it stays sharp on retina screens.
- Colour or single-colour both fine — the strip renders every mark in one tone
  so eight logos from eight brands read as one wall instead of a sticker sheet.

## Where to get them

Ask each distributor for their media or brand kit — that is the version you are
licensed to display as a stockist. A logo lifted off a website is usually the
wrong file and sometimes the wrong company entirely.
