# Customer

**Home:** `/account`  
**Shell:** Customer capp (mobile-first PWA)  
**Device:** Phone primary; desktop ≥860px keeps landing header + wide stage

## Nav (dock)

Home · Book · Queue · Blog · More

## Daily flow

1. Sign in / open app  
2. See greeting + active visit progress (or Book / Add a car)  
3. Book, check live queue, loyalty, or manage garage via More  
4. Theme: Light/Dark under More → Alerts

## Birthday

Save the date once in Settings. It locks after that save. On the birthday, Vouchers shows a code that lasts 7 days and can be used once this year. Show that code at the branch. When the bay starts the car, the same code is texted to the customer.

## Promo vouchers

More → Vouchers lists active promo codes with their rules (dates, remaining uses, wash/detailing). History shows codes already used on a visit. Quote the code to the Team Lead on the floor; do not expect the counter voice to read it.

## After a completed visit

On the account, a completed visit can be rated once. Thumbs up opens that branch’s Google review page. Thumbs down asks for a category and what happened, then files the published Customer Complaints form. Staff read it under Planner → Forms.

## Must never see

Ops queue edit, POS, payroll, finance, people, audit.
