# Branch Card Containment Design

## Approved direction

Keep Bacoor, Batangas, and Dasmariñas in a single three-column row on large desktop screens. Preserve the existing Hakum dark section, borders, Benzin display type, map-pin treatment, and responsive collapse.

## Layout rules

- Desktop branch cards use tighter padding, icon columns, and gaps so the title column has enough space.
- Desktop branch names use a smaller fluid maximum while remaining visually prominent.
- The Dasmariñas status is positioned above the title and does not consume a grid column.
- Tablet keeps the existing two-column flow.
- Mobile keeps one card per row and reduces the branch-name size enough to prevent clipping.
- No card, title, or page-level horizontal overflow is allowed at 1860px desktop or 430px mobile widths.
