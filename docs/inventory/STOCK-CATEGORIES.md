# Stock categories

Merchandise and the coffee menu can show on POS. Coffee materials and chemicals stay off POS. A coffee-menu sale takes one cup and 20 grams of beans from that branch when those two materials are marked Cups and Beans.

Branch Admin asks to add stock. The count does not move until Super Admin approves on Approvals. That approval does not create a bill. Super Admin and Assistant Super Admin can still type a corrected count. A Branch Admin cannot type over the current number.

Show in POS is a checkbox on the item. Coffee materials and chemicals stay hidden even if the box is checked.
