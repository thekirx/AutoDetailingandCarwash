# Stock categories

Coffee drinks, such as a Spanish latte, are their own items. They can show on POS and sell like any other drink. Their stock count is that drink.

Coffee stock is cups, beans, and the other supplies behind the bar. It stays off POS. Selling a drink does not subtract cups or grams of beans.

Chemicals stay off POS. Merchandise can show on POS.

Branch Admin requests a restock. The count stays put until Super Admin approves it. That approval does not create a bill. Super Admin and Assistant Super Admin can still type a corrected count. A Branch Admin cannot type over the current number.

Show in POS is a checkbox on the item. Coffee stock and chemicals stay hidden even if the box is checked. A merch item that only has a point price stays off the register until it also has a peso price.
