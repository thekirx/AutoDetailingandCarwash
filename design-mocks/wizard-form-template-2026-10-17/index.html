Wizard form template

Ops console → Planner → Forms. Adds a reusable step-by-step (wizard) form that an admin copies with Use this template, then edits in the editor they already use. The copy is a normal form: its own permanent /f/<slug> link, QR, Preview, Results, Edit, Archive.

It reuses the existing forms table and editor. Steps are stored inside the form's own settings, so existing forms do not change unless someone switches "Show as steps" on. Orange dashed outlines mark what is new.

Mock, 17 Oct 2026. Write-up: docs/forms/WIZARD-TEMPLATE.md. One open choice at the bottom (what kind of form the copy is).

2 · "Use this template" opens the editor you already have

Same Create dialog as "New detailing form", pre-filled as a Draft. New parts: the Show as steps switch, a Steps list (rename, hint, add, reorder, remove) and a Step dropdown on each field. Fields are grouped under their step. Save creates the form with its own link and QR; Edit works the same way later. Switching steps off turns any form back into one page. (Kind shows "Custom form" = option B in section 5; with option A it reads "Detailing services".)

5 · One choice for you: what kind of form is the copy?

Today the Forms tab can only create "Detailing services" forms. Everything else above is the same in both options.

B · Add a "Custom forms" kind Recommended

Copies are filed under a new Custom forms entry in "Which form", with a neutral grey Planner label and the form's own name on Planner cards.
  • Right label for sign-ups, surveys, applications, anything not detailing.
  • Needs one small database change. I hand you the SQL; nothing touches the live project until you run it or say so.
alter table public.ops_forms drop constraint ops_forms_kind_check;
alter table public.ops_forms add constraint ops_forms_kind_check
  check (kind in ('complaint','event','equipment_repair',
                  'cash_advance','detailing','custom'));

A · No database change

Copies are saved as "Detailing services" forms and appear in that list next to Detailing inquiry.
  • Works on localhost straight away.
  • Non-detailing forms get the purple "Detailing" label and a "Detailing: …" title on Planner cards.
  • Can move to B later.
